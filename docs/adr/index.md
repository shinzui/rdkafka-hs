# Architecture Decision Record

- [Admin requests have scoped native ownership and configured deadlines](admin-requests-have-scoped-native-ownership-and-configured-deadlines.md) - Topic administration retains the native client, scopes each owned request and result, validates C representations, and follows the configured native request timeout.
- [Async consumers require a threaded runtime](async-consumers-require-a-threaded-runtime.md) - Reject async consumer construction before allocation when the executable lacks the threaded runtime, while retaining synchronous consumers and runners.
- [Configuration strings reject embedded NUL](configuration-strings-reject-embedded-nul.md) - Reject embedded NUL in shared configuration setters before native marshalling while preserving ordinary native validation and empty-value semantics.
- [Consumed headers preserve wire order](consumed-headers-preserve-wire-order.md) - Headers is an ordered list that keeps every pair, repeated names and identical pairs included, and the consumer decoder returns it in the order the producer sent it; selecting a value for a repeated name is the caller's choice.
- [Consumer fatal errors are surfaced in-band](consumer-fatal-errors-are-surfaced-in-band.md) - Once librdkafka raises a fatal error on a consumer, pollMessage and pollMessageBatch return KafkaResponseError RdKafkaRespErrFatal on every call in both callback poll modes, consumerFatalError returns the cause, and the background loop destroys what it polls.
- [Consumer inputs preserve native topic and partition identity](consumer-inputs-preserve-native-topic-and-partition-identity.md) - Reject unrepresentable topic, group and partition arguments before native conversion or state changes.
- [Consumer partition operations report member errors](consumer-partition-operations-report-member-errors.md) - Preserve overall native errors before the first failing partition and retain successful effects of mixed consumer requests.
- [Consumer queue and teardown ownership](consumer-queue-and-teardown-ownership.md) - Manual assignment shares subscription queue routing, and destroyConsumer synchronously stops polling, releases queue references and destroys the client without a graceful group close.
- [Delivery callbacks transfer once and keep exceptions in Haskell](delivery-callbacks-transfer-once-and-keep-exceptions-in-haskell.md) - Mask the enqueue ownership decision, release rejected callback roots immediately, and contain delivery callback exceptions within Haskell threads while preserving per-message delivery.
- [Diagnostics borrow handles and scope native dumps](diagnostics-borrow-handles-and-scope-native-dumps.md) - Preserve caller handle ownership while flushing and closing an owned native stream, and bracket native configuration dump arrays through conversion.
- [First release scope and distribution](first-release-scope-and-distribution.md) - rdkafka-hs 1.0.0.0 is distributed as a git tag of a public GitHub repository, not on Hackage, and deliberately excludes public API renames, admin API expansion, CI, Linux broker orchestration and downstream edits.
- [Integration tests run against a project-local Redpanda](integration-tests-run-against-a-project-local-redpanda.md) - The integration suite runs only against this project's private Redpanda on Apple Container, behind a manual Cabal flag, and refuses the machine-global broker.
- [Manual sync callback polling preserves records](manual-sync-callback-polling-preserves-records.md) - Preserve manual synchronous callback polling by copying returned messages into a partition-aware FIFO with scoped native ownership.
- [Metadata results have scoped ownership and explicit errors](metadata-results-have-scoped-ownership-and-explicit-errors.md) - Copy and release native metadata and group lists within one scope, preserve nested query errors, and return unsupported group states as errors.
- [Native clients own persistent Haskell callback bridges](native-clients-own-persistent-haskell-callback-bridges.md) - Transfer persistent callback registrations to a client-independent owner released after native shutdown, with scoped cleanup for failed construction and native child handles.
- [Polled messages have one scoped owner](polled-messages-have-one-scoped-owner.md) - Mask native message acquisition, copy within its ownership scope and release every returned message before the client can be torn down.
- [Producer settings merge explicit topic keys after global keys](producer-settings-merge-explicit-topic-keys-after-global-keys.md) - Validate explicit topic properties and merge them into the effective native producer configuration after global properties without replacing its default topic configuration.
- [rdkafka-hs is a maintained fork of hw-kafka-client](rdkafka-hs-is-a-maintained-fork-of-hw-kafka-client.md) - rdkafka-hs continues hw-kafka-client under a new package name with its full git history, keeps the Kafka.* namespace and public names, and restarts its version line at 1.0.0.0.
- [Rebalance actions check and release native errors](rebalance-actions-check-and-release-native-errors.md) - Report failed native assignment actions through callback exception containment and release cooperative error objects before returning from the callback.
- [Release coverage requires behavior and ownership evidence](release-coverage-requires-behavior-and-ownership-evidence.md) - Release acceptance requires an explicit tested public-contract and native-ownership inventory, trustworthy fixtures, and source-bound compatibility evidence rather than only passing counts or aggregate coverage.
- [Release validation precedes publication](release-validation-before-publication.md) - The complete release candidate, including a scratch downstream build with renamed dependency and bounds, is validated before its tag is published, and requests close only after remote tag proof.
- [Release validation has explicit primary and expanded scopes](release-validation-has-explicit-primary-and-expanded-scopes.md) - Preserve all implemented repairs and tests while qualifying the immediate release on its demonstrated primary tuple and tracking comprehensive coverage and compatibility separately.
- [Seek reports ordered member errors and preserves initiation semantics](seek-reports-ordered-member-errors-and-preserves-initiation-semantics.md) - Preserve the public Maybe KafkaError result while reporting native overall failures first and member failures in request order, with pending markers normalized only for zero timeout.
- [Subscription properties use later values](subscription-properties-use-later-values.md) - Compose subscription topic sets by union and property maps with later values taking precedence, consistently with consumer and producer properties.
- [The Nix scaffold is seihou-managed](the-nix-scaffold-is-seihou-managed.md) - flake.nix, nix/*.nix and process-compose.yaml are regenerated by seihou and never edited or formatted by hand; project wiring lives in flake.module.nix and process-compose.override.yaml, and reconfiguration passes every non-default variable.
- [Toolchain floor is GHC 9.12 and librdkafka 2.15](toolchain-floor-is-ghc-9-12-and-librdkafka-2-15.md) - rdkafka-hs supports only GHC 9.12 and newer with the GHC2024 edition and one shared common stanza, and requires librdkafka 2.15, the version the locked Nix toolchain provides.
- [Transaction errors are decoded within native ownership](transaction-errors-are-decoded-within-native-ownership.md) - Scope native transaction error acquisition, complete decoding and destruction together while retaining public results and recovery flags.
